# 📸 GlessGroup Download Images

Служебный планировщик автотехцентра **GlessGroup**. Он работает на Windows-сервере в бесконечном цикле, раз в 30 секунд сверяет текущее время с расписанием и запускает фоновые задачи:

- разбирает и синхронизирует фотографии товаров;
- переключает call-центр по графику из Excel;
- собирает статистику по звонкам;
- считает загруженные фотографии за неделю;
- следит за актуальностью файлов выгрузки;
- присылает сообщения об ошибках в Telegram.

Результаты работы записываются в Google Таблицы.

## ✨ Возможности

| Задача | Что делает |
|---|---|
| 📂 **Разбор и синхронизация фотографий** | Берёт фотографии из папки для разбора, приводит к единому формату (до 1920×1080, сжатие), переименовывает по номеру товара и раскладывает по папкам `1`–`5`. После этого сравнивает локальные папки с папками на втором сервере и копирует недостающие файлы |
| ☎ **Переключение call-центра** | Сверяет рабочий Excel-файл с основным (по времени изменения, порог 5 минут) и при необходимости копирует его. Затем читает график из файла через Excel и включает или выключает телефоны менеджеров через API call-центра. Результат пишется в лист `LogsCallCenter` |
| 📊 **Статистика по звонкам** | Загружает данные за вчерашний день: принятые, пропущенные и исходящие звонки, общее время разговоров по менеджерам. Записывает итоги в Google Таблицу |
| 🗓 **Недельная статистика по фотографиям** | По субботам переносит количество загруженных за неделю фотографий в таблицу (лист `LogsPhotos`) по сотрудникам и обнуляет онлайн-счётчики |
| ✅ **Проверка актуальности файлов** | Проверяет дату изменения файлов выгрузки (база данных и прайс-листы Дром, Авито, 2GIS). Если файл не обновлялся больше суток, отправляет предупреждение в Telegram |
| 🚨 **Уведомления об ошибках** | Если любая задача падает, Telegram-бот отправляет администраторам название функции, время и текст ошибки |

Вспомогательная функция `offcallcenter()` в `helperscripts.py` по средам отключает всех менеджеров в call-центре.

## ⏰ Расписание

Задачи запускаются по совпадению времени (формат `ЧЧ:ММ`) с цикличным пересчётом следующего запуска:

| Задача | Следующий запуск после выполнения |
|---|---|
| Сканирование папок с фотографиями | каждый час (в `00` минут) |
| Изменение call-центра | каждый час (в `10` минут) |
| Сбор статистики по звонкам | в 00:05 |
| Недельная статистика по фотографиям | в 02:30 (выполняется только по субботам) |
| Проверка актуальности файлов | в 04:00 |
| Углублённое сканирование фотографий | в 03:47 *(пока заглушка)* |

> В текущем коде время первого запуска каждой задачи после старта программы задаётся относительно момента запуска (через 1–4 минуты), а потом переключается на постоянное расписание из таблицы выше.

## 🛠 Технологии

- **Python 3.10+** (используется `match/case`)
- **Pillow** — сжатие и подгонка фотографий
- **gspread** — запись статистики в Google Таблицы через сервисный аккаунт
- **openpyxl** и **pywin32** (`win32com`, `pythoncom`) — чтение графика call-центра из Excel
- **requests** — работа с API call-центра
- **pyTelegramBotAPI (telebot)** — уведомления об ошибках
- **tqdm** — индикатор прогресса
- **threading**, **shutil**, **ftplib** — фоновые потоки, копирование файлов, работа по FTP
- **unittest** — тесты

> ⚠️ Из-за `pywin32` и работы с Excel через COM программа запускается **только на Windows** и требует установленного Microsoft Excel.

## 📁 Структура проекта

```
GlessGroupDonloadImages/
├── main.py             # Точка входа: цикл с таймером и switcher() для выбора задачи
├── classes.py          # Все классы задач: фотографии, call-центр, статистика, проверки, уведомления
├── helperscripts.py    # Вспомогательные функции (вывод, отключение call-центра)
└── tests/
    ├── tests.py              # Тесты отправки ошибок и недельной статистики
    └── test_class_photos.py  # Заготовка тестов для class_photos
```

| Класс | Ответственность |
|---|---|
| `times` | Время запуска задач и расчёт следующего запуска |
| `class_photos` | Разбор, конвертация и синхронизация фотографий |
| `class_call_center` | Синхронизация Excel-графика и переключение call-центра |
| `class_collecion_of_information` | Статистика по звонкам |
| `class_generation_stat_uploadphotos` | Недельная статистика по фотографиям |
| `class_checks` | Проверка актуальности файлов |
| `class_send_erorr_message` | Отправка ошибок в Telegram |

## 🚀 Установка и запуск

### 1. Клонирование и зависимости

```bash
git clone https://github.com/Fllleshka/GlessGroupDonloadImages.git
cd GlessGroupDonloadImages

python -m venv .venv
.venv\Scripts\activate

pip install pillow gspread openpyxl pywin32 requests pyTelegramBotAPI tqdm
```

### 2. Файл с настройками `dates.py`

Модуль `dates.py` содержит секреты и пути, поэтому **не входит в репозиторий**. Создайте его самостоятельно. Из него код импортирует:

| Имя | Назначение |
|---|---|
| `botkey` | Токен Telegram-бота для уведомлений |
| `timetowaitingfunction` | Лимит времени ожидания потоков |
| `mainpath`, `mainpathanalysis`, `server2path` | Пути к папкам с фотографиями: основная, для разбора, на втором сервере |
| `ftpdates` | Данные FTP-сервера |
| `CREDENTIALS_FILE`, `sheetkey` | Файл сервисного аккаунта Google и ключ таблицы |
| `allsotr`, `masssotr`, `colorsforworkers` | Данные о сотрудниках, ячейках таблицы и цветах |
| `datesforexcelfiles` | Пути к Excel-файлам графика и пароль |
| `urlapi`, `urlforstatistics`, `headers`, `paramoffline`, `paramsinfo` | Адреса и параметры API call-центра |

> ⚠️ Не публикуйте `dates.py`, файл сервисного аккаунта Google и токен бота. Добавьте их в `.gitignore`.

### 3. Запуск

```bash
python main.py
```

Программа работает постоянно. Если нужно, настройте её автозапуск через Планировщик заданий Windows.

### 4. Тесты

```bash
python -m unittest tests.tests
```

## 🔒 Замечания по безопасности

- Токены, пароли и ключи нужно хранить вне репозитория (в `dates.py`, переменных окружения или менеджере секретов).
- Пути к сетевым ресурсам и идентификаторы получателей уведомлений лучше вынести из кода в конфигурацию.
